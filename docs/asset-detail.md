# 지도 안의 자산 상세

- 왼쪽 리스트와 지도 인스턴스를 유지하고, `.map-region` 내부에 `inset: 5%` 팝업을 표시한다. 팝업을 닫으면 기존 카메라·목록 스크롤이 유지된다.
- 일반 지도 탐색에서는 전체 화면이나 브라우저 top-layer dialog로 전환하지 않는다. 목록은 계속 사용할 수 있다. 닫기 버튼과 팝업 안의 Escape로 종료한다.
- 개요 / 토지 / 건축물대장 / 임대 정보 / 임차기업 / 거래 이력 / 개발·변경 이력 / 주변 / 자료 출처를 제공한다. 기존 서비스 및 권한 정책은 유지한다.
- Supabase에 저장된 자산, 동별 면적, 승인된 사진, 임대분기, 거래, 개발, 임차이전 및 검증된 건축물대장을 사용한다. 시세·매물은 포함하지 않는다.

## 추가한 저장 구조

`building_parcels`: 자산과 필지의 다대일 연결, 19자리 PNU, 토지특성, 소유구분, 개별공시지가 이력, 용도지역·지구·구역, EPSG:4326 GeoJSON Polygon/MultiPolygon, 출처·기준일. 한 건물에 여러 필지가 연결될 수 있다.

`building_places`: 교통/교육/편의시설, 위치, 직선거리, 보행시간과 경로 출처, 자료 기준일. 재저장 허용된 원천만 적재한다. 보행시간은 직선거리로 추정하지 않는다.

두 테이블 모두 `verified=true`이면서 공개 자산에 연결된 자료만 비로그인 사용자에게 제공한다. 브라우저 쓰기는 허용하지 않는다. 데이터가 없거나 조회가 실패한 상태를 구별한다.

## 실제 연결에 필요한 것

현재 VWorld 인증키는 설정되어 있지 않다. 필지/주변 데이터를 임의로 생성하지 않는다. VWorld에서 운영 도메인용 키를 발급하고 연속지적도 API의 `LP_PA_CBND_BUBUN`을 PNU로 조회하여 검증된 GeoJSON을 저장하면, 배경 지도와 토지 탭의 지도 양쪽에서 즉시 표시된다. 주소에서 면적에 맞춘 임의 사각형을 만들지 않는다. 건물 외곽선/사업구역 경계는 법정 필지 경계와 별도 데이터다.

토지 특성·이용계획·공시지가는 각 원천의 신청/접근 권한을 확인한 뒤 적재한다. 주변 시설 및 보행 경로도 원천 API 연결이 추가로 필요하다. 건축물대장과 기타 기존 데이터는 현재 검증·저장된 자산 범위에서 표시하며 전 자산 수집 완료를 의미하지 않는다.

토지 관련 외부 링크는 서비스 입구이며 선택 필지의 서류를 자동으로 발급하는 링크가 아니다.
