# 지도 안의 자산 상세

- 왼쪽 리스트와 지도 인스턴스를 유지하고, `.map-region` 내부에 `inset: 5%` 팝업을 표시한다. 팝업을 닫으면 기존 카메라·목록 스크롤이 유지된다.
- 일반 지도 탐색에서는 전체 화면이나 브라우저 top-layer dialog로 전환하지 않는다. 목록은 계속 사용할 수 있다. 닫기 버튼과 팝업 안의 Escape로 종료한다.
- 개요 / 토지 / 건축물대장 / 임대 정보 / 임차기업 / 거래 이력 / 개발·변경 이력 / 주변 / 자료 출처를 제공한다. 기존 서비스 및 권한 정책은 유지한다.
- Supabase에 저장된 자산, 동별 면적, 승인된 사진, 임대분기, 거래, 개발, 임차이전 및 검증된 건축물대장을 사용한다. 시세·매물은 포함하지 않는다.

## 추가한 저장 구조

`building_parcels`: 자산과 필지의 다대일 연결, 19자리 PNU, 토지특성, 소유구분, 개별공시지가 이력, 용도지역·지구·구역, EPSG:4326 GeoJSON Polygon/MultiPolygon, 출처·기준일. 한 건물에 여러 필지가 연결될 수 있다.

`building_places`: 교통/교육/편의시설, 위치, 직선거리, 보행시간과 경로 출처, 자료 기준일. 재저장 허용된 원천만 적재한다. 보행시간은 직선거리로 추정하지 않는다.

두 테이블 모두 `verified=true`이면서 공개 자산에 연결된 자료만 비로그인 사용자에게 제공한다. 브라우저 쓰기는 허용하지 않는다. 데이터가 없거나 조회가 실패한 상태를 구별한다.

## 실제 연결

VWorld 인증키는 비공개 파일에 설정되어 있으며 프런트엔드나 Git에는 포함하지 않는다. 연속지적도 `LP_PA_CBND_BUBUN`을 19자리 PNU로 조회해 검증한 GeoJSON을 저장한다. 배경 지도와 토지 탭 양쪽에서 표시한다. 개발사업 등록주소의 대표 필지는 사업구역 전체와 다르며, 임의 사각형이나 계획 경계를 만들지 않는다.

국가중점 API의 토지특성, 개별공시지가 이력, 토지이용계획, 소유구분을 연결한다. 토지특성은 최신 기준연월을 선택하고, 공시지가는 연도 내 가장 늦은 공시값을 표시한다. 소유자료가 여러 호실에 걸친 경우 소유구분만 집계하며 단일 변동일이나 공유인수를 추정하지 않는다. 원본 응답은 Git 제외 캐시에 보존한다.

주변 시설은 VWorld 장소 검색의 공급자 분류를 확인한 교통·교육·편의시설이다. 1km 이내 결과를 저장하고 직선거리를 계산한다. 모든 시설을 빠짐없이 포함한다는 의미는 아니다. 보행시간은 경로 API 연결 전까지 표시하지 않는다.

재수집: `vworld-catalog-parcels.mjs` → `import-parcels.mjs` → `vworld-boundaries.mjs` → `vworld-land.mjs`, 주변은 `vworld-places.mjs`. 모두 `scripts/building-register/`에 있으며 `--apply`가 있어야 DB를 변경한다. 경계 스크립트는 Node의 `--experimental-strip-types`가 필요하다. 원본 조회는 24시간 캐시를 사용한다.

검증된 원천만 공개하며 자산 접근 여부는 기존 `service_public_read` 정책을 따른다. `published` 값을 임의로 변경하지 않는다. 건물대장 식별 범위가 다른 복합자산과 원천 응답이 없는 항목은 연결을 보류한다. 토지 관련 외부 링크는 서비스 입구이며 서류 자동발급 링크가 아니다.

## 2026-09-28 수집 결과

비로그인 DB 조회로 확인한 공개 범위: 건축물대장 연결 271개 자산, 층별 정보 13,073건, 전유·공용면적 105,193건. 원본 지번에서 함께 수집된 다른 건물 자료는 공개 연결과 구분해 보존한다.

토지 연결 361개 자산 / 대표·부속 필지 연결 631건, 실제 경계·특성·공시지가 각각 629건. 동일 필지가 여러 자산에 연결될 수 있다. 주변 시설은 좌표가 있는 363개 자산에 98,236건 연결했다(자산별 1km 반경 중복 포함).

10개 운영자산의 대장 연결은 복합건물 범위 불일치 또는 원천 결과 없음으로 보류했다. 3개 자산의 대표필지와 2개 부속필지는 VWorld 경계 응답이 없어 임의로 생성하지 않았다. 도보시간은 별도 보행 경로 API가 필요하다.

## 지도 마우스 오버

줌 15 이상에서는 카드 또는 개별 지도 말풍선에 마우스를 올리면 해당 자산의 필지 경계를 표시한다. 마우스를 떼거나 다른 자산으로 이동하면 이전 경계를 제거한다. 비동기 응답이 늦게 도착해도 이전 자산의 경계가 다시 나타나지 않도록 취소 상태를 확인한다. 경계 데이터는 화면 세션에서 캐시하며 배율은 변경하지 않는다. 상세페이지를 연 자산의 기존 경계 표시는 유지한다.
