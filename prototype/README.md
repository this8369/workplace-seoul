# Workplace Seoul · 첫 화면 시안

Codex의 정돈된 사이드바, 중립적인 색상, 얇은 구분선과 절제된 조작부를 참고한 화이트 기반 인터랙티브 초안입니다.

## 실행

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 구현 범위

- 지역·건물 상태·면적·편의시설 필터, 검색과 정렬
- 지도와 건물 목록 연결, 개념 지도 이동·확대
- 건물 미리보기와 상세 탭
- 관심 건물 저장(localStorage), 최근 조회, 최대 3개 건물 비교
- 데스크톱 및 모바일 레이아웃, 키보드 검색(⌘K / Ctrl+K)

## 시안 데이터

건물명 외의 수치, 설명, 위치는 UX 검토를 위한 예시입니다. 지도는 실제 지도 서비스가 아닌 직접 작성한 개념도이며, 건물 이미지는 직접 제작한 SVG 일러스트입니다. 외부 API, Google Sheets 및 실제 자산 DB에는 연결하지 않았습니다.

기본 글꼴은 IBM Plex Sans KR이며 네트워크가 없으면 기기 기본 한글 글꼴로 표시합니다.
