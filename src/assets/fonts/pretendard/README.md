# Pretendard

Pretendard Variable 1.3.9, bundled locally for consistent Korean UI typography on macOS and Windows.

- Source: https://github.com/orioncactus/pretendard/tree/v1.3.9
- File: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`
- License: SIL Open Font License 1.1; see `LICENSE.txt`.
- Supported weights: 45–920. The site preloads this font and retains the existing brand fonts.
